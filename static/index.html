📖 OBS Virtual Camera Setup Guide
Step-by-step instructions to set up your virtual camera feed
1
Install OBS Studio
Download and install OBS Studio from the official website. OBS is free, open-source, and works on Windows, macOS, and Linux.
2
Create a New Scene
In OBS, click + under Scenes to create a new scene (e.g., "Zoom Bot"). This scene will hold your fake video feed source.
3
Add a Video Source
Under Sources, click + and choose one of:
• Media Source — for a looping video file of a person
• Image — for a static photo
• Video Capture Device — for a real or secondary webcam
Resize and position the source to fill the canvas.
4
Start Virtual Camera
In the OBS Controls panel (bottom right), click Start Virtual Camera. This makes OBS output appear as a webcam device that Zoom can select.
5
Configure Zoom to Use OBS
In Zoom Desktop Client, go to Settings → Video and select "OBS Virtual Camera" from the camera dropdown. You should see your OBS scene preview in the Zoom settings window.
6
Run Zomo Bot
With OBS Virtual Camera running and Zoom configured, go to the Controls tab and click Start Bot. Zomo will join the meeting, enable the camera (showing your OBS feed), and start chatting!
